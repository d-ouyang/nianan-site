# CHANGELOG

> 版本号规则：`MAJOR.MINOR.PATCH`
> - **MINOR**：完成计划里的一个任务（P0-1 → 0.1.0，P0-2 → 0.2.0 ……），进入 P1 后继续顺延
> - **PATCH**：已发布功能的修补
> - 每个版本对应一份 `docs/iterations/v<版本>-<slug>.md` 迭代文档
> - 进度总览见 `docs/PLAN.md`
