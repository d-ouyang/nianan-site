## 已定的技术决策

- React 19 + Vite 7 + TS + Tailwind v4；动效 = ogl（背景）+ motion（UI 动画），GSAP/Lenis 到 P0-3 再装
- 暗色 + 单一强调色 `#00E0A4`（青绿），全站不引入第二个色相
- Hero 用 ogl shader；three.js/R3F 版留作后续对比实验（用户要求做一版对比）
- R3F 对比版做完后两版实测对比再定稿（对比维度：首屏体积、帧率、观感）
