# v0.1.0 —— P0-1 项目骨架（补记）

> 日期：2026-09-28。本篇在 P0-2 完成后补记（当时版本号体系尚未建立）。
> 验收截图：`docs/p0-1-screenshot.png`

## 1. 目标与范围

搭起 Vite + React 19 + TS + Tailwind v4 的可跑骨架，定义全站设计令牌（暗色 + 单一强调色）。

## 2. 实现内容

- Vite 7 + React 19 + TS strict（`tsc -b` 分 project references），`@` 路径别名
- Tailwind v4（`@tailwindcss/vite`）：令牌全部进 `@theme`，工具类与 CSS 变量同源
- 设计令牌（`src/styles/tokens.css`）：canvas `#09090B` / surface 两级 / line 两级 / fg·muted·faint 三级灰 / accent `#00E0A4` 单色相三级；`--na-accent-rgb` 供 shader 配透明度
- `base.css`：暗色滚动条、selection、focus-visible、`prefers-reduced-motion` 全局兜底
- dev 固定 `127.0.0.1:5180` + strictPort

## 3. 否掉的方案 + 代价

| 方案 | 否掉原因 | 代价 |
|---|---|---|
| Tailwind v3.4 | v4 是 CSS-first 且构建快；bits 组件绝大多数只用工具类 | v4 对 `@theme` 里 `clamp()` 的解析有坑（见 §4），需要自己踩掉 |
| Next.js / Nuxt | 服务器 4C4G 已满，不能养常驻 Node 进程 | 失去 SSR/文件路由；本站也不需要 |
| 令牌分两层（语义层 + 原子层） | Tailwind 的 `@theme` 变量本身就是 `:root` 变量，两层是重复 | 少了一层间接，改色只需改一处 |

## 4. 踩坑与修复

1. **Tailwind v4 的 `size / line-height` 简写在 `clamp()` 上解析错乱**：`--text-hero: clamp(2.75rem, 9vw, 6.5rem) / 1.05` 会让 `/` 后内容并入变量值，`text-hero` 失效回退 16px。修法：line-height 写独立的 `--text-hero--line-height`。（grep 构建产物时还差点被压缩后的「末条声明无分号」误导成变量吞 CSS，复核后确认是 grep 模式问题）
2. **Vite dev 默认 host=localhost 在 macOS 解析成 `::1`**：只监听 IPv6，`curl 127.0.0.1` 拒连但日志正常，极易误判服务没起。修法：`server.host: '127.0.0.1'`。
3. **端口漂移**：5173 被 rag-qa-system 占用，Vite 静默漂到 5174。修法：`port: 5180, strictPort: true`。

- playwright 截图 + computed style 双验证：bodyBg / accent / hero 字号 104px 全部符合令牌
