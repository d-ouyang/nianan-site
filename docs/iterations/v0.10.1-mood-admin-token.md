# v0.10.1 · 心情后台记住查看口令

> 关联版本：0.10.1（PATCH，已发布功能的修补）
> 一句话结论：**心情后台的查看口令在加载成功后记在这台浏览器里，下次打开自动填上；口令不对就清掉。**

## 1. 背景

v0.10.0 的 `public/mood-admin.html` 把口令只放在当次输入框里，刷新就要重输。查看记录的人每次都要再贴一遍 `MOOD_ADMIN_TOKEN`。

## 2. 改动

- `public/mood-admin.html`：键名 `nianan.mood-admin.token`。页面打开时若本地有口令就填进输入框，不自动请求。加载成功后写入；接口返回 401 时删除，避免错误口令一直被填回来。浏览器禁止写入时这次仍用输入框里的口令。
- `package.json`：0.10.0 → 0.10.1。
- `docs/CHANGELOG.md`、本文件。
