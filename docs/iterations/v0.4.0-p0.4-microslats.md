# v0.4.0 —— P0-4 reactbits 动效层：MicroSlats Hero 背景

> 日期：2026-09-29。
> 截图：`docs/p0-4-microslats-hero.png`（桌面 1440×900，光标划过触发流体交互后的瞬间）

## 1. 目标与范围

把 P0-2 的 Aurora 极光背景替换为 reactbits 的 `MicroSlats`：

- 首页背景改为「可交互的流体 slats 海」——光标划过会搅动波纹、点击会溅起水花；
- 严格使用单一强调色 `#00E0A4`（slat 主体）+ 更亮的 `#9dffe6`（浪尖 glint），背景 `#09090B`；
- 保留三向降级：reduced-motion、移动 ≤768px、无 WebGL2 全部走静态辉光；
- 维持预算：首屏 JS gzip < 200KB、单一 WebGL canvas、离屏暂停。

## 2. 实现内容

- `src/components/bits/MicroSlats.tsx`：reactbits `MicroSlats-TS-CSS` 完整源码进入仓库，适配 Vite（去掉 `'use client'` Next.js 指令），保留 `import './MicroSlats.css'`
- `src/components/bits/MicroSlats.css`：组件基础布局 `.micro-slats { position:relative; width:100%; height:100%; overflow:hidden; }`
- `src/components/sections/Hero.tsx`：
  - 用 `MicroSlats` 替换 `Aurora`
  - 传入 `color="#00E0A4" glintColor="#9dffe6" backgroundColor="#09090B" preset="swell" interactive intro lean={0.4}`
  - 压暗层从全局 `bg-canvas/35` 改为中心径向暗角，避免 slats 被压死
  - 保留底部 `bg-gradient-to-b` 与下一屏过渡
- `src/lib/capabilities.ts`：`canRunWebGL()` 不变，继续负责「要不要初始化 WebGL 背景」；MicroSlats 内部也有自己的 WebGL2 守卫作为二道保险
- 依赖：无新增，`ogl` 与 `motion` 已存在

## 3. 否掉的方案 + 代价

| 方案 | 否掉原因 | 代价 |
|---|---|---|
| 继续调 Aurora 参数 | 用户反馈「看不出效果」，微调颜色/速度无法解决「太平淡」 | 放弃已调好的 Aurora，换全新组件 |
| `npx shadcn add @react-bits/MicroSlats-TS-CSS` | 沙箱 symlink 限制不稳定，且 reactbits 的 shadcn registry JSON 本身已包含完整源码；直接复制更可控 | 失去 `shadcn update` 自动更新能力，后续上游改动需手动 diff |
| `backgroundColor="transparent"` | 页面 canvas 就是 `#09090B`，但透明会让 slat 间隙直接暴露底层 DOM；把背景色交给组件自己画更利于 shader 合成 | 多维护一个颜色 token 与页面同步 |
| 保留 `bg-canvas/35` 全屏压暗 | 会把本来明亮的 crest glint 压暗到几乎看不见，失去「酷炫」效果 | 改为中心径向暗角，只压文字背后一小块 |
| 直接全局引入 GSAP 做 slat 动效 | reactbits 已经把波动画做在 shader 里，无需再用 ScrollTrigger；额外 GSAP 会增加首屏体积 | 沿用组件内部 rAF + WebGL 管线 |

## 4. 踩坑与修复

- **上次用户粘贴的 MicroSlats 源码没持久化到磁盘**：会话中断后源码丢失。修法：从 reactbits shadcn registry `https://reactbits.dev/r/MicroSlats-TS-CSS.json` 取 `files[1].content` 逐字还原。
- **Playwright headless 看不到 WebGL2**：Chrome for Testing 默认禁用 ANGLE SwiftShader， canvas 黑屏。修法：启动参数加 `--enable-unsafe-swiftshader --use-gl=angle --use-angle=swiftshader --ignore-gpu-blocklist`。
- **互动效果需要真实 cursor 事件触发**：只加载不会出波纹，脚本里做了三段 `mouse.move` 后才出现流体扰动。

| 指标 | 预算 | 实测 |
|---|---|---|
| 构建 | `tsc -b && vite build` 通过 | ✅ |

| WebGL canvas 数 | ≤ 1 | 1 |
| 画布尺寸 | 铺满 1440×900 | **1440×900**（drawing buffer 同尺寸） |

| 交互 | 鼠标划过/点击产生流体扰动 | Playwright 模拟光标后截图可见波纹 |
| 文字可读性 | 名字与副标题不被背景淹没 | 中心暗角 + slat 间隙露出 dark canvas，可读 |
