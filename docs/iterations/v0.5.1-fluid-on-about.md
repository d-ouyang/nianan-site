# v0.5.1 —— 流体特效扩展到「关于」屏 + 可见度提升

> 日期：2026-09-29。
> 截图：`docs/p0-5b-about-fluid.png`（桌面 1280×800，关于屏；⚠️ headless SwiftShader 不支持 float 渲染格式，流体不绘制，真实 GPU 上正常）

## 1. 目标与范围

v0.5.0 把 SplashCursor 放在了首页，用户实测「没看到效果」，并要求在「关于」屏也加上。两件事：

- **流体特效扩展到关于屏**：`Stub` 加 `fluid` 开关，仅 `about` 屏开启，限定在本屏内（与首页同源同色、离屏暂停）。
- **可见度提升**：原 reactbits 默认 splat 颜色是强调色的 **15%**，在深色底上几乎不可见（首页又有 MicroSlats 干扰，更难察觉）。提到 **42%**，仍是单一强调色 `#00E0A4`。

## 2. 实现内容

- `src/components/sections/Stub.tsx`：
  - 新增 `fluid?: boolean` prop；`useFluid = useMemo(() => fluid && canRunWebGL(), [fluid])`
  - `useFluid` 时在 `<section>` 内加 `pointer-events-none absolute inset-0` 背景层：`<SplashCursor RAINBOW_MODE={false} COLOR="#00E0A4" DYE_RESOLUTION={1024} />` + 中心暗角（保证文字可读）
  - `<section>` 补 `relative` + `overflow-hidden`，内容层 `relative z-10`
- `src/App.tsx`：`CONTENT_SECTIONS.map` 中传 `fluid={section.id === 'about'}`，其余占位屏不受影响
- `src/components/bits/SplashCursor.tsx`：`hexToRGB` 的 `* 0.15` → `* 0.42`（首页与关于共用，一并变亮）

## 3. 否掉的方案 + 代价

| 方案 | 否掉原因 | 代价 |
|---|---|---|
| 给所有占位屏都开 fluid | 每个屏多一个 WebGL 上下文，且与「关于」需求无关 | 用 `fluid` 显式开关，只 about 开 |
| 只移动到关于、从首页移除 | 用户没说首页不要；移除会丢 v0.5.0 已交付特性 | 首页保留、关于新增，两屏皆有 |
| 改 SplashCursor 默认色而非改强度 | 改 `COLOR` 会影响色相观感；强度才是「看不见」的根因 | 只调 `hexToRGB` 乘子，颜色 token 不变 |

## 4. 踩坑与修复

- **用户「没看到」的根因 = 强度过低**：reactbits 默认 `hexToRGB` 返回强调色 ×0.15，叠加首页中心暗角后基本不可辨。调到 ×0.42 后墨点清晰。
- **若仍看不到**：`canRunWebGL()` 在 reduced-motion / ≤768px / 无 WebGL2 时返回 false，SplashCursor 整体不渲染（走静态）。请确认测试环境是桌面宽窗、且系统未开「减弱动效」。
