# v0.6.0 · 页脚备案信息组件

> 关联版本：0.6.0（MINOR，新功能）
> 一句话结论：**新增 `Footer` 组件承载版权与 ICP 备案信息（主办单位 + 备案号外链工信部官网），接入主布局最底部；备案号链接严格使用 `<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener noreferrer">`，颜色/字号全部走设计令牌，移动端无横向溢出。**

## 1. 背景

站点要上线，需要按《互联网信息服务管理办法》在页面底部展示 ICP 备案号，且备案号必须是可点击、指向工信部官网首页（https://beian.miit.gov.cn/）的链接。此前页面没有页脚区域（Dock 是悬浮导航，不算页脚），所以本版新建页脚组件并接入。

## 2. 设计决策

- **位置：`src/components/sections/Footer.tsx`**。页脚是文档流里的一个页面区块（不是悬浮 UI），归 `sections/` 而不是 `ui/`。
- **不进 `SECTIONS` 注册表**。备案页脚不是内容区块，不参与 Dock 高亮 / 滚动进度 / hash 同步，进注册表反而会污染导航语义。
- **底部 padding 必须给足（pb-24 / sm:pb-28）**。Dock 是 `fixed bottom-5` 悬浮在页脚上方，页脚是文档流最后一个元素，padding 不够时备案信息会被 Dock 压住、点不到链接。
- **颜色只用令牌**：文字 `text-muted`（#9a9aa3，对 #09090b 背景对比度 ≈ 7.1:1，达标 WCAG AA）、悬停 `text-fg`；没有引入任何硬编码色值或新色相。
- **布局**：桌面端一行左右分布（© 版权在左，备案在右）；≤640px 折成纵向居中，备案行内部 `flex-wrap` 换行 —— 窄屏靠换行消化，不产生横向滚动。
- **不动现有视觉**：只新增一个组件 + App 挂载一行，Hero/Stub/Dock/令牌零改动。

## 3. 改动

- 新增 `src/components/sections/Footer.tsx`：© 年份（运行时取当前年）+ 「主办单位：欧阳鼎」+ 备案号外链。
- `src/App.tsx`：在内容区块之后、`<Dock />` 之前挂载 `<Footer />`（文档流最底部；Dock 是 fixed 悬浮，渲染顺序不影响其位置）。
- `package.json` 版本 0.5.2 → 0.6.0；`docs/CHANGELOG.md`、`docs/PLAN.md` 补记录。
