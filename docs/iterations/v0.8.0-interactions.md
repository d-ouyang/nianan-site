# v0.8.0 · 简历交互

> 关联版本：0.8.0（MINOR，新功能）
> 一句话结论：**名字画布把「欧」和尺寸标签完整画出来；首页跳转和底部导航悬停时出现瞄准框；滚过首屏后右下角出现回到顶部；技能四组收进同一色相的深绿文件夹，纸张和标签用主题绿。**

同一分支上、本版之前还有一笔未单独发版的提交：工作经历改成时间轴，并补上教育经历。这次和本版一起推到远端。

## 1. 背景

v0.7.0 的简历单页能往下读完，交互还停在纯文字。名字特效的左缘和高度被画布切掉。卡片底部的跳转和 Dock 没有悬停反馈。滚下去之后只能靠导航回来。技能只有两组短列表，和首页卡片的质感也不统一。

## 2. 设计决策

- **名字左对齐时先给描边和选框留边。** 笔画贴在画布 x=0 时，描边、选框和尺寸标签会画到画布外面。「欧」的左边和标签被切掉。布局按这些装饰留出边距，画完再把越界的字形挪回来。名字容器加高，并用 `-ml-5` 抵消内边距，笔画仍然比上方的 `nianan.site` 往左 10px。热更新不会重跑这块画布，看效果要整页刷新。
- **瞄准框只圈住两排按钮。** 首页跳转和底部 Dock 各挂一个，鼠标在这两排里才换成瞄准框，页面其余地方仍是系统光标。颜色用强调色 `#00E0A4`，套住目标后变成 `#5CFFD0`。首页四个字是「技能、项目、经历、联系」；「经历」只改这排按钮，区块标题仍是「工作经历」。
- **回到顶部离开右边缘，系统滚动条收掉。** 滚动超过 0.75 屏后，按钮以弹性动画出现；系统开启减少动效时只淡入。点按或把弹弓拖开再松开，都平滑滚回首页。按钮放在 `right-16` / `sm:right-24`，给拖拽留出空间，也不压住 Dock。页面原生滚动条隐藏，阅读进度仍是右侧那条细线。
- **技能是四只文件夹，托盘和首页卡片同一层毛玻璃。** 分组是前端、后端、AI Agent 工程、运维 / 部署。悬停打开，点翻盖也能打开，点里面的标签不收起。托盘用 `bg-canvas/35 backdrop-blur-sm`，格子从后面透出来。
- **文件夹和主题绿用同一色相的深浅，不用灰。** 灰和 `#00E0A4` 没有色相关系，叠在一起发闷。夹层 `#14352D`，翻盖 `#1E5244`，纸张和标签都是主题绿 `#00E0A4`，标签上的字是近黑 `#09090B`，文件夹上的字是 `#ECECEE`。打开时亮的纸从深色夹子里翻出来。
- **文案只改确认过的事实。** 英文名按邮箱写成 Ding Ouyang。角色是「前端·全栈·AI Agent」。年限改为「前端开发 10 年，AI Agent 开发 1 年。」技能四组按现有条目写入 `profile.ts`，没有新编雇主或职责。

## 4. 验证

浏览器在 `http://127.0.0.1:5180` 看过：

- 整页刷新后，「欧」的选框和尺寸标签完整，笔画比站点名往左约 10px。
- 悬停首页「经历」和 Dock「项目」时，瞄准框锁在按钮上，另一处的瞄准框保持隐藏。点击「联系」和 Dock「技能」会平滑滚动。
- 滚过约 0.75 屏后回到顶部以弹性动画出现，点击后约 1.2 秒回到首页并消失。按钮离右边缘约 96px，不压住 Dock。
- 技能托盘的模糊和首页卡片一致（`blur(8px)`，画布色 35% 透明）。文件夹夹层为 `rgb(20, 53, 45)`，纸张和标签为 `rgb(0, 224, 164)`。

`pnpm run build` 在打这个版本前跑过，类型检查和 Vite 构建都通过。
