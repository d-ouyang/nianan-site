# v0.9.1 · 锅圈项目区精简

> 关联版本：0.9.1（PATCH，内容修正）
> 一句话结论：**锅圈商城卡片按用户反馈重排——新增「首页首屏优化」，移除「两级异步分包」、撤下仓库规模数字，保留多分支架构、自研 Vite 插件 + easycom、CMS、一起吃拼单、AI 点单。**

## 1. 背景

v0.9.0 把锅圈项目放进了项目区，但用户复核后给出明确取舍：两级异步分包不展示、仓库规模数字（89 分支 / 1269 源文件 / 649 条件编译 / 57 拆出主包）不突出、补一条「首页首屏优化」；多分支 + 条件编译、自研 Vite 插件 + easycom、CMS 配置化、一起吃拼单、AI 点单全部保留。

## 2. 改动

- `src/content/profile.ts`：`projects` 里锅圈条目——
  - 新增亮点「首页首屏优化：扛住大流量下的首屏体验」（preloadRule 分包预加载 + manualChunks 主包瘦身 + 请求聚合缓存 + 图片懒加载/CDN + 长列表分页折叠）；
  - 删除「两级异步分包，拆掉 2MB 主包限制」整条；
  - 原「自研 Vite 插件」亮点去掉 57 组件口径，只留 componentPlaceholder 自动注入 + easycom 四规则；
  - `metrics` 撤下 89/1269/649/57 四个数字，保留「5 端一套代码 / 裂变业态 / 零售全链路」；
  - 多分支架构亮点去掉「649 处 #ifdef」计数；
  - 迭代表里「分包」改为「首屏」，去掉 57 组件表述。
- `package.json`：0.9.0 → 0.9.1。
- `docs/CHANGELOG.md`、`docs/PLAN.md`（P0-5·补二 行沿用 0.9.0 标记，本次为补丁）、本文件。

## 3. 验证

- `tsc -b --noEmit` 通过（pnpm 在本地触发依赖重装失败，属环境问题；用 `node_modules/.bin/tsc` 直跑通过）。
- `vite build` 通过；Playwright 实测锅圈卡片：`hasHomepageOptimization=true`、`hasTwoLevelSubpackage=false`、`has89/has1269/has649/has57=false`、`hasMultiBranch/hasVitePlugin/hasCMS/hasTogether/hasAI=true`、`overflow=true`、无 console 报错。
- 首页优化的具体毫秒数未在仓库留存基线，文档中按「以微信开发者工具 Audits / 录屏回弹实测为准」诚实标注，未编造数字。

## 4. 遗留

- 「一起吃」拼单与 AI 点单的完整实现细节已另出一份独立面试备忘（不在网站上），见 `gqsh-mp-wx/docs/锅圈-拼单与点单-面试备忘.md`，含主要能力 / 重难点 / 坑点 / 面试题参考答案。
