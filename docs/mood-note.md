# 联系区下方的心情纸条

问句用中文。页面正文是中文，「今天你开心吗？」也按中文写。邮箱本身是拉丁字符，输入条里的占位用 `you@email.com`，不把中文塞进弯曲的字线上。滑条两端写「低落」「开心」，不写 sad / happy。

## 位置

放在联系卡片下面，仍在「联系」这一节里，不新开导航项。和卡片隔开一截，让弯曲的输入条有自己的一块空地。底部导航不改。

## 展示

1. 问句：「今天你开心吗？」
2. 一条滑条，从左到右是低落到开心。数值 `mood` 从 -1 到 1，默认 0（平静）。
3. 滑条带动 `CurvedInput` 的 `bend`：`bend = mood × 28`。往左，条子往下塌；往右，条子往上拱；正中是平的。
4. 条子用来填访客自己的邮箱。按钮文案是「留下」。
5. 颜色只用站点已有色：底 `#121215`，字 `#ECECEE`，占位 `#9A9AA3`，描边 `#35353D`，按钮和邮箱图标 `#00E0A4`，按钮字 `#09090B`。

`CurvedInput` 按给出的源码放进 `src/components/bits/`，去掉 `'use client'`。弯曲、光标、按钮的交互不改，只由外面传入文案和颜色。

## 邮箱校验

点「留下」或按回车时校验，输入过程中不打断。

通过的条件：

- 去掉首尾空白后不为空
- 总长不超过 254，`@` 左边不超过 64
- 恰好一个 `@`
- 左边不为空，不以点开头或结尾，不含连续的点
- 右边是带点的域名，标签只含字母、数字和连字符，不以连字符开头或结尾
- 最后一段是至少两个字母的后缀

不探测这个邮箱是否真实存在。那要等后台接口。

不通过时，条子下面写「写一下邮箱」或「这个邮箱格式不对」。

## 现在不提交到后台

接口还没有。校验通过后不发请求，也不把邮箱存进浏览器。

页面写：「邮箱没问题。接口接上后，后台能看到这封邮件和现在的心情。」

接上时只改 `src/lib/moodNote.ts` 里的 `submitMoodNote`。请求体固定为：

```json
{ "email": "you@email.com", "mood": 0.4 }
```

`email` 是去掉首尾空白后的邮箱。`mood` 是 -1 到 1，一位小数：-1 低落，0 平静，1 开心。成功后再把上面那句换成后台返回的确认。
